Introduction

JavaScript is a high-level, interpreted programming language used to make web pages interactive.

It runs in browsers and on servers (Node.js).

  • Dynamic typing
  • First-class functions
  • Event-driven
Variables

Use let for reassignable, const for constant references.

let counter = 0; const PI = 3.14159;

Avoid var due to hoisting.

Functions

Functions are first-class citizens.

function greet(name) { return `Hello ${name}`; } const add = (a, b) => a + b;

Arrow functions don't bind their own this.

Loops
for (let i = 0; i < 10; i++) {} arr.forEach(x => console.log(x)); for (const item of items) {}

Prefer functional iteration where possible.
