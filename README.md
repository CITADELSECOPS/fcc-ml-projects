# freeCodeCamp Machine Learning with Python — Final Projects

Working Python solutions for the 5 final projects of the [freeCodeCamp Machine Learning with Python certification](https://www.freecodecamp.org/learn/machine-learning-with-python/).

## Projects

| # | Project | Files | Approach |
|---|---------|-------|----------|
| 1 | [Rock Paper Scissors](./rock-paper-scissors/) | `RPS.py` | Order-5 Markov chain pattern matching |
| 2 | [Cat and Dog Image Classifier](./cat-dog-classifier/) | `cat_dog_classifier.py` | TensorFlow CNN with data augmentation |
| 3 | [Book Recommendation Engine using KNN](./book-knn/) | `book_recommendation.py` | scikit-learn NearestNeighbors (cosine) |
| 4 | [Linear Regression Health Costs Calculator](./health-costs/) | `health_costs.py` | TF Dense layers + Normalization |
| 5 | [Neural Network SMS Text Classifier](./sms-classifier/) | `sms_classifier.py` | TF Embedding + GlobalAveragePool + Dense |
